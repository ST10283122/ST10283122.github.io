Machine Learning: Teaching Computers to Learn from Data

Brief Description

This blog explains machine learning in simple terms, drawing on definitions and research from computer science sources. It describes how computers can learn from data instead of being told exactly what to do, and gives a detailed example of how this is used in real life through email spam filtering.

Disclaimer

This blog is written for learning purposes only. It gives a simple and general view of the topic based on selected academic and industry sources and it should not be used as the only source for making important technical or business decisions.

Introduction

Machine learning is one of the most important parts of artificial intelligence and it is the technology behind many of the smart features people use every day without necessarily realising it. Instead of giving a computer strict, step by step instructions for every possible situation, machine learning allows a computer to look at examples of data and figure out patterns on its own, rather than relying purely on fixed, pre written rules (IBM, n.d., cited in ecqi.healthit.gov, n.d.).

This blog explains what machine learning is in a simple way, using a widely used definition from the field, and shows how it is used in everyday life through a common real world example that most people encounter regularly.

Definition of Concepts

Machine learning is a way of teaching computers to learn from examples instead of following fixed rules written entirely by a person. IBM describes it as a branch of artificial intelligence that focuses on using data and algorithms to imitate the way humans learn, gradually improving the accuracy of the computer's decision making over time (IBM, n.d., cited in ecqi.healthit.gov, n.d.). In practice, the computer is given a large amount of data and it looks for patterns within that data during a process often called training once it finds these patterns, it can use them to make predictions or decisions on new information it has not seen before.

The more relevant data the computer has during training, the better it usually becomes at finding accurate and useful patterns. This is quite different from traditional programming, where a person must write out every single rule the computer needs to follow in advance, which becomes impractical for tasks that are too complex or too varied to describe with a fixed set of rules.

Use Case Example

A common and very familiar example of machine learning is the email spam filter. The system is trained using many examples of emails that have already been marked as spam and emails that have been marked as normal and a machine learning algorithm, such as a Naive Bayes classifier, calculates the probability that a new email is spam based on the words and patterns it contains (Biswas, 2017). Over time the system learns the patterns that usually appear in spam messages such as certain words, unusual formatting or suspicious links.

Once trained, the spam filter can look at new, previously unseen emails and decide whether they are likely to be spam or not, without a person having to check every single message by hand (Biswas, 2017). This shows how machine learning can save time and effort by handling repetitive classification tasks that would take humans far longer to do manually while still adapting as new types of spam messages appear over time.

It is worth noting that spam filters and similar classification systems are not immune to the wider concerns raised about fairness in machine learning since biases in the training data can still affect how such systems behave in practice (Barr et al., 2024).

Future Direction or Trends

In the future, machine learning is expected to become even more accurate as more data becomes available and computing power continues to improve, which may lead to smarter systems that can handle more complex, less repetitive tasks than simple classification. As these systems are increasingly used in high stakes decision making from credit scoring to healthcare there is likely to be continued growth in how widely machine learning is applied across different industries.

There is also a growing and important focus on making machine learning fairer and safer so that the patterns it learns do not lead to unfair or harmful outcomes for people. Barr et al. (2024) note that biases can enter machine learning models in complex ways depending on the context in which they are used, which is why researchers have called for context aware approaches to selecting fairness measures rather than relying on a single, one-size fits all metric.

Conclusion

Machine learning allows computers to learn from data and improve over time instead of following fixed instructions written entirely in advance. Understanding this concept, along with its real world applications and its ongoing fairness challenges, helps explain how many modern technologies are able to make smart, adaptive decisions.
